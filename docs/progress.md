## 1. P1 已交付基础

- FastAPI、SQLAlchemy、SQLite WAL 和固定版本 Alembic 迁移。
- 单管理员交互初始化、登录、退出、密码恢复、会话失效与持久化失败限速；不提供生产默认密码。

- 合并账户支持多张有效卡，独立账户最多一张有效卡；修改银行默认值不改变历史账户模式。

- 分次还款、计划还款、重复提交保护、撤销 / 取消和审计；计划不减少待还金额。
- 每账户 / 币种仅汇总最新已确认账单；旧未结清账单单列待核对，避免重复累加结转金额。
- 父级停用阻止新录入，但不隐藏已有未结清账单。
- 一致性 SQLite 在线备份、完整性检查、健康检查与导出的 OpenAPI 契约。

- Vue 3、TypeScript、Vite、Element Plus 管理后台。

### 部署基础

- API 非 root 镜像、静态管理前端 / Caddy 网关、Compose、持久数据卷和 HTTPS 配置。

## 3. P2 已实现

### 邮箱与来源

- 管理后台新增「邮箱与导入」页面；多个 IMAP / POP3 邮箱、SSL / STARTTLS、连接测试、启停、收取间隔、首次范围、筛选词和指定日期补扫。
- 邮箱凭证以 Fernet 加密保存；API 与 worker 必须共用主密钥。凭证不回显，编辑时留空保留原值，密码首尾空格不丢弃。
- IMAP 使用只读选择、UIDVALIDITY / UID 与 BODY.PEEK；POP3 依赖 UIDL 持久去重，不删除邮件。不支持 UIDL 的服务不作不安全降级。
- 增量游标、目标变更隔离、日期范围、分批同步、失败来源重取和跨邮箱输入复用；来源记录保留邮箱归属。
- EML / 文本型 PDF 上传、内容寻址文件存储、来源及任务筛选分页、管理员专属纯文本预览。重复上传不重复创建来源，导入不会生成账单。

### 输入准备与安全

- 仅使用成熟库进行通用 MIME 解包、HTML 转纯文本、PDF 文本读取，不识别银行、金额、还款日或交易行。
- PDF 加密、扫描件、损坏资料和不支持附件有明确状态，不实现 OCR 或本地银行字段解析。
- 强 TLS 校验、公网 DNS 地址检查与连接固定、路径边界、输入 / 文件 / 存储大小限制和网络总时限。
- 转换在受时限约束的子进程运行，Linux 另有 CPU / 地址空间限制；预览不执行原邮件 HTML、不加载外部资源。

### 任务与部署基础

- SQLite 持久任务、定时同步、单邮箱互斥、任务去重、租约、心跳、过期恢复、token fencing、有限退避和人工重试（保留失败记录）。
- 独立 worker 支持单次运行与健康检查。网络 / 转换工作不占用长数据库写事务；旧租约或旧配置不能提交结果。
- P2 增量迁移只新增邮箱、来源、输入、任务与心跳表，本地测试确认保留 P1 财务数据。
- Compose 更新为 API / worker / gateway 三服务，共享数据库、资料目录与主密钥；上传网关上限单独配置，不放宽全部 API。
- 生产 / 开发依赖分别锁定完整闭包，并包含 Linux aarch64 条件依赖 greenlet；不是 ARM 容器实测结论。

## 5.1 P3 已实现与历史本地验收

### 模型与持久任务

- 可更换供应商的 `/v1/chat/completions` HTTPS 适配，不依赖模型 SDK；固定提示词 / schema / 校验器版本，无工具调用。

- 模型密钥 / 已知私人文本替换列表加密、不回显，配置版本保护；默认模型关闭，自动发送 / 发布关闭。
- 复用 P2 独立 worker、SQLite 持久队列、租约与心跳；单模型并发锁不阻塞邮件转换，调用前持久化预算预留。
- 每日 / 任务调用次数限制、有限重试、超时或崩溃未知记录；token / 单价不足时费用未知，按币种区分估算。
- 相同输入 / 配置 / 提示词 / schema 缓存运行，跨来源复用；force / 人工重试明确创建新收费可能，旧候选保留。

- 一封多摘要、多币种、可无详单；严格 JSON 拒绝重复键 / NaN、字段 / 精度 / 日期关系校验、原文引用存在性检查。

- 不曾创建正式管理员或填写真实邮箱、模型密钥；测试账号只存在于隔离测试环境，不是生产默认凭证。
- 网关后当前不信任客户端提供的转发来源；个人部署共用限速范围，后续按实际代理环境确认。
- 还款记录只是用户标注，不执行支付、不确认到账；保存计划不发送提醒。

- `app.cli backup` 只备份数据库。P2 / P3 完整恢复还需原资料 / 输入目录与同一主密钥；资料文件未应用层加密，须保护 VPS / 卷权限。整卷导出、密钥恢复及异地加密备份在 P6 演练，不能仅依赖 DB 快照。
- worker 心跳只表示任务进程近期存活，不表示邮箱登录 / 同步成功；各邮箱实际状态须查看任务和来源。
