# 安卓使用与开发说明 · 0.4.0

更新：2026-10-09。当前交付为P4源代码和个人测试用Debug APK，不是正式发行版。安卓设备测试已编写 / 编译但尚未运行；请先用测试账单验收，勿依赖此版本提醒还款。

## 1. 安装和配对

- 最低Android 8.0（API26）；当前compile / target API35。首次安装可将 `D:\code\Bills\android\app\build\outputs\apk\debug\app-debug.apk` 传到自己的可信手机，按系统提示允许该来源安装，仅在测试期间授权。
- 使用升级后的0.4.0后台，在「安全与设置」生成一次性配对码。10分钟有效，仅使用一次；默认设备凭证90天。
- App输入根服务地址、配对码和设备名称。正式服务用 `https://你的域名`，不要输入管理网页路径、`/api/v1`、账号密码、查询参数或片段。当前不支持部署在路径前缀下。
- 使用可信有效的HTTPS证书。客户端不忽略证书错误、不跟随重定向，服务器跳转时请填写最终地址；不在URL携带设备令牌。
- 配对成功后显示账单首页；设备只能读取账单 / 账户，标记 / 撤销还款及创建 / 取消计划。没有银行、邮箱、模型、卡片或账单编辑功能。
- 合并银行的多张卡归到后台已设置的同一还款账户，App只计算该账户账单一次。模式以后台已有账户为准，不能在手机修改。

### 本机开发连接（仅Debug）

Release只允许HTTPS；Debug仅允许localhost、127.0.0.1和10.0.2.2使用HTTP，不能直接用局域网明文IP连接。

- 模拟器访问电脑本机API：`http://10.0.2.2:8000`。后台网页仍在电脑浏览器访问 `http://localhost:5173` 生成配对码。
- USB真机测试可使用 `adb reverse tcp:8000 tcp:8000`，App填写 `http://127.0.0.1:8000`；开发API保持电脑loopback监听，不公开测试服务。设备须由本人明确授权调试，用后撤销调试授权。
- 不填写真实秘密到测试代码，不把开发服务器或临时测试管理员暴露到互联网。

## 2. 查看账单

- 首页按币种分别汇总，可按银行和持卡人筛选；合并账户不因多张卡重复计算。
- 最新已确认账单与历史未结清分开显示。旧未结清不直接累加到本期汇总，以免把结转重复计入；请后台核对。
- 账户页分页，历史按当前页的月份折叠；详单、还款和计划分页读取。不要把当前20条误当成全部记录，使用下一页查看。
- 进入详情先取得摘要version，再读取同版本详单，保留重复交易及原顺序。无详单 / 部分详单显示实际状态，不虚构交易；App不显示模型证据或原邮件。
- 下拉刷新或刷新按钮联网更新。未知金额不当作零；停用账户的已有未结清信息仍可查看，但不能新增还款 / 计划。

## 3. 标记还款和保存计划

- 使用联网刷新后的已确认账单；输入金额、时间和可选备注。表单时间明确按北京时间（Asia/Shanghai）解释，与手机所在时区无关。
- 一次部分还款对应一条记录，可分次标记；记录只改变用户标记的待还金额，不执行支付、不验证银行到账。
- 金额超出记录待还或时间早于出账，服务端要求再次确认。App显示待提交内容，用户核对后再明确确认；不自动接受异常。
- 未来还款使用「计划还款」；计划不减少待还。**P5尚未实现：保存计划不安排通知、不发邮件，没有后台提醒保障。**
- 还款撤销和计划取消需原因，记录保留。账单金额 / 日期 / 模式等错误只能后台核对和修订，手机不能编辑。

### 收不到确认时

网络断开或请求超时，可能已在服务端记录。App在发送前将路径、内容和同一Idempotency-Key加密保存；只显示「待核对」，不会宣称提交成功或自动后台补发。

1. 保持原连接和原提交，不重新新建一条。
2. 查看待核对卡片内容，恢复网络后点「核对重试」，保持同一提交标识，服务端返回已存在记录或完成一次提交。
3. 应用关闭后可恢复同一待核对内容。明确异常拒绝才可核对后确认或放弃；经历不确定结果后的一般4xx也不等于上次一定未记录。
4. 如凭证过期、设备被撤销、清理本机或卸载导致待核对内容消失，先在后台检查服务端还款记录，不能推断记录也被删除。
5. 服务端成功确认后若刷新失败，界面提示已确认但金额非最新；先刷新，不再次录入同一笔。

## 4. 离线、隐私和断开

- 只缓存已经查看成功的页面；每设备随机scope隔离，最多200页，超过30天的缓存不回退。没有看过的页离线无法打开，缺页不当作完整空列表。
- 缓存显示同步时间及只读状态。缓存不能用于新增还款 / 计划；恢复网络刷新后才恢复正常操作。本期余额以最近取得的服务端数据为准。
- 凭证、待核对内容及缓存payload采用Android Keystore / AES-GCM加密；存入noBackup目录，关闭系统备份 / 迁移。Room页索引和同步时间不作为金融明文内容；手机安全和锁屏仍需本人保障。
- 界面启用FLAG_SECURE，禁止截屏及敏感最近任务预览。未申请通知权限；日志不记录设备令牌、配对码或财务正文。
- 收到401或本机已知凭证到期，会清理本机授权、缓存和待核对内容。**离线无法实时知道后台撤销**，未到本地到期且仍在缓存期限内的已有页面可能继续只读；恢复联网后执行验证。
- 「连接」→「断开连接 / 更换服务」尝试撤销当前设备并清理本机。断网时本机仍清理，但远端撤销未保证，需到后台撤销该设备；其他设备和管理员不受影响。
- 本机清理、卸载或断开不删除后台账单和还款。

## 5. 从源码构建

安装JDK17、Android SDK平台35及对应构建工具。使用Android Studio配置SDK，或在 `android/local.properties` 填写本机SDK路径（不提交源码）。

```powershell
cd D:\code\Bills\android
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
.\gradlew.bat assembleRelease lintRelease
```

工程包含Gradle8.9 wrapper及分发SHA256、AGP8.7.3、Kotlin2.0.21、Compose BOM2024.12.01、Room2.6.1，依赖版本锁定在 `app/gradle.lockfile`。首次构建需访问官方依赖源；更新依赖应显式重新写锁并回归。

- 可安装测试产物：`app/build/outputs/apk/debug/app-debug.apk`，包名 `dev.bills.app.debug`，版本0.4.0-debug，使用开发调试签名。
- Release产物：`app/build/outputs/apk/release/app-release-unsigned.apk`，**未签名，不能作为正式可安装发行版交付**。P6再配置个人签名并妥善保存密钥，不提交仓库。
- JVM报告：`app/build/reports/tests/testDebugUnitTest/index.html`；lint报告：`app/build/reports/lint-results-debug.html` / `lint-results-release.html`。
- Room缓存schema已导出，后续变更缓存结构须升级版本 / 提供迁移或明确重建缓存；缓存不是后台数据的备份。
