# 账序后台界面优化

## 设计与范围

按已批准的 `frontend-design` 方案实施“精装账簿式工作台”：保留账序品牌，以墨绿导航、暖白纸面、黄铜细节、宋体标题与等宽数字建立统一视觉。

- `admin-web/src/style.css`：统一设计变量与 Element Plus 主题；合并旧框架覆盖；规范标题、面板、表格、筛选、弹层、状态摘要和登录页。
- `admin-web/src/App.vue`、`components/WorkspaceSidebar.vue`：共享导航组件，桌面固定侧栏、1024px 以下文字菜单抽屉；支持焦点循环、Esc/遮罩关闭、切页关闭、退出登录与跳至内容。
- 概览：强调待还金额、近期到期和待核对，优化风险提示、账单行与手机布局；增加首次加载失败后的重试入口。
- 账单、账户卡片、年费、模型核对：统一局部样式与信息层级，改善筛选、金额、日期、详情与编辑器；敏感字段继续默认隐藏。
- 邮件中心、任务队列、设置与登录页通过公共样式统一，不重写其业务逻辑。
- 页脚版本由 `package.json` 读取，避免独立硬编码失真。

界面优化不修改后端、数据库模型、API 契约、Android 业务、金额计算或认证逻辑；没有新增依赖。发布时 Web 与 Android 版本统一为 `0.7.0`，Android `versionCode` 递增为 `22`。原有未跟踪的 `agent.md` 保持不变，不纳入提交。

## 验证结果

- `npm run build`：通过 TypeScript 与 Vite 生产构建。Vite 仍提示入口包大于 500 kB；本次未引入新依赖，未扩展到分包优化。
- 对全部变更 Vue/CSS/TS 文件执行 Prettier 检查：通过。
- `git diff --check`：通过。
- `npm run test:e2e -- --reporter=list`：**69 项全部通过**（Chromium，单 worker）。
- 新增 `admin-web/tests/ui-layout.spec.ts`，14 项测试覆盖 1440、1024、768、390、320px：全部路由与登录、空数据、长卡名、多卡、大金额、多币种、风险提示、账单抽屉、年费弹窗、页面溢出、下拉筛选、菜单焦点/关闭/退出、减弱动态效果、错误重试。
- 既有测试保留金额与筛选语义、到期数字强调、风险/结清颜色、卡片隐私与紧凑弹窗高度等断言。部分测试更新为显式打开手机菜单或指定业务弹层；另校准两处现有行为断言（`tracked_only` 参数、账户管理页签），未改变应用业务逻辑。
- `0.7.0` 版本更新后重新执行 Web 生产构建、版本文件格式检查，以及布局与模型流程共 15 项测试：全部通过，并同步更新截图。Android 本次仅更新版本元数据，未重新构建。
