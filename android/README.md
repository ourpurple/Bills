## 本次账单页简化（0.4.9）

- 删除“全部待还”右侧的“X 笔待核对”，删除汇总下方的“全部账户 · 最新已确认账单 · 按币种汇总”说明和独立“本期账单”下拉区域，去除其占用的留白。
- “全部待还”标签在左，汇总金额移至同一行右侧；多币种在右侧分别排列，不换算相加，保持隐藏金额与无已确认金额提示。
- 本期账单、近期到期（7天内）、历史未结清切换收进右上角“筛选”的“账单范围”，重置恢复本期账单。各银行账单行的金额和到期状态不变。
- 补充标注区域移除、左右布局、多币种/隐藏金额、窄屏大字体及筛选切换/重置的合成界面测试；仅编译，尚未在设备执行。

## 本次交易明细连续展示

- 交易列表取消“上一页 / 下一页”和页码，末尾仅显示“共 X 条”。月份列表同样连续展示；账户、还款记录与计划的分页不变。
- 安卓端自动读取当前账单版本的全部交易页并连续展示，不修改现有服务端接口和分页上限。
- 保留服务端交易原顺序与重复记录；合并前校验版本、总数、页码、页面大小及提取状态。
- 任意一页使用缓存，合并结果仍为非最新/只读，并采用最早同步时间。中途失败保留已读取交易，明确提示未完整读取及下拉重试，不假装已展示全部。
- 增加纯本地多页合并、重复交易、缓存、空账单、读取中断及元数据变化测试；界面测试覆盖仅显示条数、不再显示交易分页控件。

- 新增合成数据界面测试，覆盖红框内容移除、更多菜单入口、缓存提示及分页提取状态。

## 页面方案与已实现功能

### 账单
- 白色背景、扁平银行列表、淡色分隔线。
- 显示银行、持卡人、卡片尾号或多卡数量、本期金额、待还金额及到期状态。
- 以大字号展示“今 / 明 / 天后到期”，临近到期和逾期使用红色；已标记还清、未知日期、作废分别显示。
- 全部待还按币种分别汇总；银行/持卡人筛选只影响列表，明确标注汇总仍为全部账户。
- 右上角“筛选”中提供本期账单、近期到期和历史未结清切换，保留下拉刷新，不再显示逐条更新按钮。
- 刷新仅读取现有服务端数据，不触发收信、导入或模型识别。无已确认账单不等于没有欠款。

### 详单
- 灰紫色页头、白色内容区、黄色选中下划线。
- 从账单页点击任意账单，进入该还款账户的月份列表；默认所有月份收起，不自动读取首月交易。
- 选择还款账户，按月份展开/收起账单，展示账期、金额和原顺序交易列表；月份摘要自动读取全部服务端分页后连续展示，不显示翻页控件。
- 重复交易保持独立行，不合并或去重；通过账单版本读取详单。
- 可切换账单明细、还款记录及还款计划；月份与交易连续展示，账户、还款记录与计划保留分页。
- 进入单张账单详情后提供返回按钮、账单信息和固定黄色“标记已还款”操作。
- 仅进行个人还款标记，不执行支付或确认银行到账；计划不减少待还，且不安排通知。
- 保留撤销标记/取消计划时的原因填写，以及未确认提交的幂等核对重试。

### 设置
- 展示服务地址、设备名称、授权时间、读取状态、同步时间和待核对提交。
- 本机隐藏金额开关适用于列表、详单、账单信息及还款记录。
- 默认详单账户为本机偏好；支持查找账户分页之外保存的默认账户。
- 断开/更换服务前确认清理本机凭证及缓存；未确认远端撤销时明确提示。
- 保留加密缓存与凭证、禁止真实财务页面截屏及系统备份等既有保护。

### 0.4.8 删除月份列表分页区域

- 删除详单月份列表中的“上一页 / 下一页”、页码 / 总条数及“仅展示当前分页账期”说明，不增加常规替代信息块。
- 安卓端自动依次读取该账户已有的所有月份摘要，沿用原有分页 API 和加密缓存，不改动服务端或 Web；月份默认收起，展开才读取该月交易。
- 合并前检查账户、页码、页面大小、总数、行数和账单 ID 重叠，保留原顺序、同月不同币种及账单版本，防止漏读或显示重复月份行。
- 任意一页来自缓存，整份历史仍标记为缓存 / 非最新 / 只读，并使用最早缓存时间。读取中断保留已验证的月份；只有不完整时提示下拉重试，不把部分历史误示为全部。
- 补充跨页历史、空列表、缓存来源、不完整读取、账户隔离和重叠检测的单元测试；新增超过 20 个月仍可展开末月且无分页区域的合成界面用例。界面测试仅编译，尚未在设备执行。

### 0.4.7 账单入口改为账户月份列表

- 账单页的所有账单行统一进入对应还款账户的月份列表，与底部“详单”共用界面；不再直接进入单张详情和还款页。
- 初次进入、重新点击同一账户、切换账户、刷新及翻页均默认收起全部月份；进入账户时回到列表顶部。只读取已有月份摘要，点击某月后才读取该月版本对应的交易和记录。
- 月份较多时与参考图一致保留历史分页；每月交易仍连续展示、只显示总条数，不增加交易分页按钮。未展开的月份不提前拉取交易。
- 展开某月后，通过右上角“…”→“账单详情与还款”保留原有个人还款标记/计划入口；金额隐藏、缓存只读及未确认提交保护不变。
- 增加月份入口及缓存来源单元测试，补充账户隔离、默认收起、逐月展开、重新进入和缓存还款禁用的合成界面用例，并同步更新专用测试服务流程。界面用例仅编译，未在设备执行。
